gh275 demo

A throwaway fixture spec for octo-feather issue 275: realcase greet prints a greeting. Never build it.

User stories

As a user, I run realcase from the terminal and it greets me.

Acceptance criteria

Given a user with realcase installed, When they run realcase greet with no name, Then the command exits 0 and prints Hello, world! on one line.

Given a user with realcase installed, When they run realcase greet with a name, Then the command exits 0 and prints Hello, followed by that name and ! on one line.

Modular boundaries

The greet command owns the greeting. Caller-facing seam: the realcase greet CLI. Dependency direction: self-contained. Observable scope: the command's stdout, stderr and exit code.

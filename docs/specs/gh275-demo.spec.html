gh275 demo (overlap)

A throwaway fixture spec for octo-feather issue 275: realcase wave prints a farewell. Never build it.

User stories

As a user, I run realcase from the terminal and it waves goodbye.

Acceptance criteria

Given a user with realcase installed, When they run realcase wave with no name, Then the command exits 0 and prints Goodbye, world! on one line.

Given a user with realcase installed, When they run realcase wave with a name, Then the command exits 0 and prints Goodbye, followed by that name and ! on one line.

Modular boundaries

The wave command owns the farewell. Caller-facing seam: the realcase wave CLI. Dependency direction: self-contained. Observable scope: the command's stdout, stderr and exit code.
